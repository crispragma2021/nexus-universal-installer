# NEXUS Suite - Human Virtual Synergy

**Instalador universal para Linux con interfaz gráfica.**

## ⚠️ IMPORTANTE
**NO abras el script en un editor de texto.**
**NO hagas doble clic en el archivo desde el navegador.**

Sigue las instrucciones de **terminal** que están abajo.

---

## 🚀 Instalación

Abre una **terminal** y ejecuta:

```bash
git clone https://github.com/crispragma2021/nexus-suite.git
cd nexus-suite
chmod +x install.sh
./install.sh
```

## ✨ Características
- Interfaz gráfica con Zenity
- Multi-distro (Debian, Arch, Fedora)
- Menú persistente
